# 星瞳離線版安裝補丁

## 最新版本：V1.9.0.1（未加殼）

下載：

```text
星瞳-1.9.0.1-離線版安裝補丁-未加殼-20261031.zip
```

本安裝包：

- 只部署本機離線授權服務與啟動／停止腳本。
- 不包含、不修改、不覆蓋官方 `星瞳.exe`。
- 只接受原始 V1.9.0.1：SHA-256 `23C0268439D70A1221217699EB95568F38F30E61D6C4D5EDA6E0D32002F13020`。
- `MStarBotOfflineAuth.exe` 為未加殼單檔版，不需要 `.ompayload`。
- 會保留既有 `MStarBotOfflineAuth.key`。

## 安裝

1. 先執行舊的 `停止星瞳離線服務.bat`，並完全關閉星瞳。
2. 解壓縮完整 ZIP，不能直接在 ZIP 內執行。
3. 雙擊 `安裝離線版.bat`。
4. 選擇包含原始 V1.9.0.1 `星瞳.exe` 的資料夾。
5. 安裝後執行星瞳資料夾內的 `星瞳-離線模式.bat`。

安裝包本身不附客戶 KEY。可在安裝前將 `MStarBotOfflineAuth.key` 放在 `安裝離線版.bat` 同層；已安裝過的電腦則會保留 `_offline` 裡原有的 KEY。

## 停止與移除

- 停止服務：執行星瞳資料夾內的 `停止星瞳離線服務.bat`。
- 移除並還原安裝前腳本：執行安裝包內的 `移除離線版.bat`。
- `星瞳.exe` 不會被移除或覆蓋。

## 驗證狀態

已完成安裝保全、EXE 雜湊不變、KEY 保留、舊 `.ompayload` 備份／移除、服務隔離連接埠啟動／停止／重開、移除還原及 ZIP 內部雜湊驗證。

尚需由實際使用者完成：本未加殼服務在正式星瞳資料夾的登入、重開機後啟動及第二台電腦測試。

## 舊版本

`星瞳-1.8.9.6-離線版安裝補丁-v6-final-20261026.zip` 僅供 V1.8.9.6 使用，不得安裝到 V1.9.0.1。
