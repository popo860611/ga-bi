# 星瞳離線版安裝補丁

## 最新版本：V1.9.0.4（未加殼）

下載：

```text
星瞳-1.9.0.4-離線版安裝補丁-未加殼-20261106.zip
```

本安裝包：

- 只部署本機離線授權服務與啟動／停止腳本。
- 不包含、不修改、不覆蓋官方 `星瞳.exe`。
- 只接受原始 V1.9.0.4：SHA-256 `9878A6C63B4D6A0775D32CC5ABD23E76B0189FD54A0C20E499AD197EE1F7DF87`。
- `MStarBotOfflineAuth.exe` 為未加殼單檔版，不需要 `.ompayload`。
- 未加殼版不需要 `MStarBotOfflineAuth.key`；若目標已有 KEY，安裝器會保留。
- 離線啟動時會保留其他設定並自動記住登入金鑰 `LOCAL-LAB-001`，新電腦不必第一次手動輸入。
- 加殼安裝若曾漏裝服務側檔，啟動腳本會從 `payload\_offline` 自動同步缺少的 `.ompayload` 與 KEY，不需先手動開啟服務。

## 安裝

1. 先執行舊的 `停止星瞳離線服務.bat`，並完全關閉星瞳。
2. 解壓縮完整 ZIP，不能直接在 ZIP 內執行。
3. 雙擊 `安裝離線版.bat`。
4. 選擇包含原始 V1.9.0.4 `星瞳.exe` 的資料夾。
5. 安裝後執行星瞳資料夾內的 `星瞳-離線模式.bat`。

未加殼版可直接啟動，不需要先產生或放置客戶 KEY。

## 停止與移除

- 停止服務：執行星瞳資料夾內的 `停止星瞳離線服務.bat`。
- 移除並還原安裝前腳本：執行安裝包內的 `移除離線版.bat`。
- `星瞳.exe` 不會被移除或覆蓋。
