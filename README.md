# 星瞳 1.8.9.6 離線版安裝包

此安裝包只適用於 **星瞳 1.8.9.6**。安裝程式會先檢查 `星瞳.exe` 的 SHA-256，版本不符時會停止，不會強行覆寫。

## 安裝

1. 先完全關閉星瞳。
2. 解壓縮本 ZIP，不能直接在 ZIP 內執行。
3. 雙擊 `安裝離線版.bat`。
   - Windows會顯示UAC權限確認，請按「是」；此權限只用來停止舊離線服務及覆寫程式檔。
4. 選擇原本星瞳的安裝資料夾（資料夾內必須有 `星瞳.exe`）。
5. 安裝完成後，使用安裝目錄內的 `星瞳-離線模式.bat` 啟動。

登入金鑰：

```text
LOCAL-LAB-001
```

同一組離線金鑰可在另一台已安裝本補丁的電腦使用；它只會送到該電腦的 localhost 離線服務。

離線啟動器會在本機 `127.0.0.1:8765` 啟動服務，再開啟星瞳。服務只監聽 localhost。

## 停止與移除

- 只停止服務：執行安裝目錄內的 `停止星瞳離線服務.bat`。
- 如果舊服務因 PID 紀錄遺失而無法停止：執行本包的 `強制停止離線服務.bat`，再重新安裝。
- 還原安裝前檔案：執行本包的 `移除離線補丁.bat`，並選擇相同安裝目錄。

安裝前的 EXE 與授權設定會保存在：

```text
<星瞳目錄>\backup\offline-1.8.9.6-日期時間\
```

## 驗證

啟動後可在瀏覽器開啟：

```text
http://127.0.0.1:8765/health
```

應看到 `"ok": true`。

如果登入顯示「找不到此授權金鑰」，表示程式沒有連到本機服務。請勿直接雙擊 `星瞳.exe`，應關閉後重新執行 `星瞳-離線模式.bat`，再確認 `/health`。

仍失敗時，執行安裝目錄內的 `離線診斷.bat`；它會檢查健康狀態、直接測試 `LOCAL-LAB-001`、EXE雜湊與設定檔編碼。


## 注意

- 不會搬移 `config.json`、`profiles`、地圖、模板或 YOLO 模型。
- 換電腦後仍需在新電腦重新選擇／綁定遊戲視窗。
- 如果星瞳日後更新，請先移除本補丁，再針對新版本重新製作；不要把 1.8.9.6 EXE 覆蓋到新版安裝目錄。
